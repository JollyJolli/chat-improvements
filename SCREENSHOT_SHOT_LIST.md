# Genuine Minecraft screenshot shot list

**All project gallery/banner/icon media must be created by humans or captured directly in Minecraft — no AI-generated or AI-edited images.** Do not upload private chats, real player identities without consent, IP addresses or authentication details. A human-designed original icon is optional; omit one if unsure.

1. **Main hero (16:9).** Real in-game Minecraft screenshot showing several lines of readable Dark Neon chat while playing. Use a private world with fake/example chat content from consenting test players.
2. **Vanilla vs mod.** Two genuine screenshots under identical game, resolution, chat and light settings; accurately label them. Do not visually fake a comparison with editing.
3. **Expanded chat.** Press T and show the actual redesigned input frame, background, messages and accurate link behavior.
4. **Themes.** Capture Cyan, Violet, Amber and Lime in-game using the real style menu. Four small screenshots or a gallery, not synthesized.
5. **Actions.** Capture [C] copy, [@] mention highlight and [M] suggestion with test usernames only. Do not misrepresent Quick Mention as automatically sending.
6. **Configuration.** Show /ci tabs and compact pagination at a realistic GUI scale (not a generated mockup).
7. **Limitations.** Screenshots should not suggest player heads work universally on big servers. Document issue #8 in the description instead.

Recommended human workflow: clear chat, launch a local test world, set options, take screenshots with the game's native screenshot key, review for privacy, crop manually if necessary, and retain unaltered originals for traceability.
