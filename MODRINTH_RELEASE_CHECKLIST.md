# Modrinth publication checklist (not yet approved)

**Current state:** Chat Improvements v0.4.0-rc.1 is a *release candidate*, not a published Modrinth project. Building a working JAR does not by itself establish eligibility to publish.

## Owner review — required

- [ ] Confirm that the project complies with [Modrinth Content Rules](https://modrinth.com/legal/rules), especially Section 6 on generative AI.
- [ ] Perform and document **primary, significant human creative development** (design, implementation, review, original contributions). Modrinth disallows projects created primarily or entirely by generative AI. **Prompting and in-game testing alone may not be sufficient** to qualify.
- [ ] Enable the "Contains AI-generated content" project disclosure where appropriate, including AI-assisted code, description and publishing material.
- [ ] Do **not** upload AI-generated or AI-edited images as project icons, banners, screenshots, gallery images or in descriptions. Capture genuine in-game screenshots; create any branding through human-made methods, or omit an icon.
- [ ] Review source code, bundled assets and license permissions; ensure no copied assets/code from other chat mods and keep accurate MIT license/attribution information.
- [ ] Choose accurate mod type, Fabric loader, Minecraft 26.2 support and beta/stable release status. Do not claim compatibility with other Minecraft versions or loaders unless tested.
- [ ] Write a clear English description of the functionality, controls, dependencies, privacy model and **known big-server player-head limitation** (#8).
- [ ] Ensure any externally interacting functionality and other applicable content disclosures are accurately assessed.

## RC technical sign-off — required

- [ ] PR #30 CI build succeeded for the **exact final candidate commit**.
- [ ] Validate the installable JAR from the artifact, not the `-sources.jar`; verify checksum if generated by CI.
- [ ] Remove other Chat Improvements JARs from `.minecraft/mods`, then launch Minecraft 26.2 + Fabric + matching Fabric API on Java 25.
- [ ] Run the full `V04_RELEASE_CANDIDATE.md` and `V04_QA_MATRIX.md` checks with screenshots of real Minecraft.
- [ ] Test upgrading from v0.3, settings persistence after restart, and reset-default behavior.
- [ ] Mark incomplete compatibility tests accurately and keep unresolved #8 open.
- [ ] Obtain **explicit owner approval** before merging PR #30 into `main` or creating a public Modrinth release.

## Publishing after approval

- [ ] Confirm project page/slug, ownership, license, release type and visibility.
- [ ] Attach the verified primary Fabric JAR, not a developer/sources-only JAR.
- [ ] Include the changelog and the explicit limitation on large public servers.
- [ ] Upload genuine in-game images only; do not fabricate test results or misrepresent compatibility.
- [ ] Check the live Modrinth listing once submitted, verify file metadata and disclosures, and link the release from the GitHub README.

Policies may change: recheck before publishing.
